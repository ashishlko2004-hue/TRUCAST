# TRUCAST
Official Enterprise Authentication Module for TRUCAST Solutions. A high-performance, secure onboarding system designed to provide a seamless and visually engaging entry point for enterprise users.
🌟 Overview
This module handles the core user journey for TRUCAST Solutions, ensuring a secure and visually engaging entry point for enterprise users. It features high-fidelity UI elements and robust form handling.

## 🚀 Key Features
- **Secure Onboarding:** Full Login, Sign Up, and Password Recovery flows.
- **Advanced Validation:** 
    - Real-time Email format checking (`Patterns.EMAIL_ADDRESS`).
    - Strong Password enforcement using Regex.
- **Premium UX (User Experience):**
    - **Glassmorphic UI:** Modern blurred effects and interactive gradients.
    - **Assistive Keyboard:** Context-aware keypads (Email/Password specific).
    - **Feedback Loops:** Shake animations and Haptic feedback on errors.
- **Interactive Recovery:** Premium "Forgot Password" flow with pulsing animations and smart dialogs.

## 🛠 Tech Stack
- **Language:** Kotlin
- **Toolkit:** Jetpack Compose (1.7.5+)
- **UI Architecture:** Material 3 Design
- **Navigation:** Compose Navigation Components
